# CampusTrack

## Student Attendance Monitoring System

CampusTrack is a web-based Student Attendance
Monitoring System developed as a Web Systems
Technology (WST) academic project.

The system supports two user roles:
Instructor and Student.

## Features

### Instructor

- Instructor Registration and Login
- Class Management
- Student Enrollment
- Attendance Session Management
- Attendance Recording (Present, Late, Absent)
- Attendance History and Editing
- Attendance Reports
- CSV Export
- Dashboard Analytics

### Student

- Student Registration and Login
- Personal Attendance Dashboard
- Attendance History
- Attendance Percentage by Class

### Modern Web Features

- Chart.js Data Visualization
- JavaScript Fetch API
- Persistent Dark Mode
- Progressive Web App (PWA)
- Responsive Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
- Chart.js
- PHP
- MySQL
- XAMPP (Local Development)
- Git and GitHub

## Local Development

Requirements:

- PHP-compatible web server
- MySQL or MariaDB
- Web browser

The database must be configured in the local
config.php file.

Database credentials and test data are not
included in the public source code.

## Project Purpose

CampusTrack is an academic demonstration
system. It is not an official university
attendance platform.
